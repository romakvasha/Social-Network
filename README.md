# Social Network

Соціальна мережа на React + Redux + TypeScript. Працює з публічним API
[social-network.samuraijs.com](https://social-network.samuraijs.com).

## Можливості

- **Авторизація**: вхід/вихід, «запам'ятати мене», капча після кількох невдалих спроб.
- **Профіль**: перегляд будь-якого користувача (`/profile/:userId`), редагування свого профілю,
  зміна статусу (подвійний клік), завантаження аватарки.
- **Пости**: додавання, лайки, видалення (локально).
- **Пошук користувачів**: пошук за іменем, фільтр «друзі / не друзі», пагінація,
  follow/unfollow. Фільтр і сторінка зберігаються в URL, тож посиланням можна поділитися.
- **Чат**: загальний чат у реальному часі через WebSocket, з автоматичним перепідключенням.
- **Діалоги**: локальні діалоги з формою повідомлень.
- **News / Music / Settings**: новини, плейлист з обраним, перемикач темної теми.
- Сторінка 404, глобальний показ помилок мережі, адаптивна верстка для телефонів.

## Запуск

Потрібен Node.js 16+ і Yarn 1.

```bash
yarn install
yarn start        # dev-сервер на http://localhost:3000
yarn test         # тести (jest + testing-library)
yarn build        # production-збірка в папку build/
yarn deploy       # публікація build/ на GitHub Pages
```

Для входу потрібен акаунт на social-network.samuraijs.com. Без входу доступні
пошук користувачів і перегляд чужих профілів.

## Структура

```
src/
  api/          HTTP (axios) та WebSocket клієнти
  redux/        редʼюсери, action creators, thunks, селектори
  components/   сторінки та спільні компоненти
  hoc/          withAuthRedirect, withSuspense
  types/        спільні TypeScript-типи
  utils/        валідатори форм
```
